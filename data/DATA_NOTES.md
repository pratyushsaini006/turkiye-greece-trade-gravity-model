# Data provenance and verification checklist

The CSV in this repository was extracted from the `Raw Data` sheet of the user-provided workbook `Gravity_Model_Correct Results.xlsx`.

Before describing this dataset as fully reproducible, verify and document:
- source URL and publication/version for each series;
- units and price basis for exports and GDP;
- tariff measure definition and whether rates are percentages or indices;
- exact transformation used for each `ln` variable;
- treatment of zero or missing values;
- whether the original data have been revised since the paper was written.

The original workbook is not included in this repository by default. Keep it locally as the source artifact unless there is a reason and permission to publish it.
